# 블루투스 저울

## 개요

일반적인 BLE 저울 프로토콜을 구현하는 블루투스 저울 앱을 개발합니다. 이 앱은 BLE
저울과 통신하여 체중 데이터를 수집하고, 사용자에게 시각적으로 표시하는 기능을
제공합니다.

## 주요 기능

1. **BLE 저울 연결**: 사용자가 BLE 저울과 페어링하고 연결할 수 있는 기능.
2. **데이터 수집**: 저울에서 체중 데이터를 수집하고 저장하는 기능.
3. **실시간 체중 표시**: 저울에서 수집한 체중 데이터를 실시간으로 사용자에게
   표시하는 기능.
4. **이력 관리**: 사용자가 체중 데이터를 기록하고, 이전 기록을 조회할 수 있는
   기능.
5. **다중사용자 지원**: 여러 사용자가 각각의 체중 데이터를 관리할 수 있는 기능.

## 기술 스택

- 프로그래밍 언어: Dart
- 프레임워크: Flutter
- BLE 통신: flutter_blue 패키지 또는 적당한 BLE 라이브러리
- 데이터 저장: SQLite 또는 Hive
- 상태 관리: Provider

## 구현 상세

1. **BLE 저울 연결**
   - flutter_blue 패키지를 사용하여 BLE 장치를 검색하고 연결합니다.
   - 사용자가 저울을 선택하고 페어링할 수 있는 UI를 제공합니다.
   - 마지막으로 연결된 저울 정보를 저장하여 다음 실행 시 자동으로 연결할 수
     있도록 합니다.
2. **사용자 선택**
   - 앱 시작 시 사용자 선택 화면을 제공하여 여러 사용자가 자신의 데이터를 관리할
     수 있도록 합니다.
   - 최초 실행시 사용자의 닉네임, 성별, 나이, 키 등의 정보를 입력받아
     저장합니다.
   - 이후 실행 시에는 저장된 사용자 목록에서 선택하거나 새 사용자를 추가할 수
     있도록 합니다.
   - 사용자 목록은 메인화면에 2x2 그리드 형태로 표시됩니다. 성별에 따라 아이콘이
     다르게 표시됩니다.
   - 신규 사용자 등록을 위한 버튼을 제공하여 사용자가 쉽게 추가할 수 있도록
     합니다.
   - 앱을 새로 기동할 때는 마지막으로 선택한 사용자를 자동으로 선택하여 편리성을
     높입니다.
   - 사용자를 선택하지 않고 측정할 수도 있도록 '게스트' 모드를 제공합니다.
3. **데이터 수집 및 실시간 표시**
   - 저울에서 전송되는 체중 데이터를 수신하고, 실시간으로 화면에 표시합니다.
   - 체중 데이터는 그래프 형태로 시각화하여 사용자가 쉽게 이해할 수 있도록
     합니다.
4. **이력 관리**
   - 사용자가 체중 데이터를 기록하고, 날짜별로 조회할 수 있는 기능을 제공합니다.
   - 체중 변화 추이를 그래프로 시각화하여 사용자가 자신의 체중 변화를 쉽게
     파악할 수 있도록 합니다.
   - 목표 체중 설정 기능을 추가하여 사용자가 목표 체중에 도달할 수 있도록
     동기부여를 제공합니다. (목표 체중도 그래프에 표시)
